Quick Start

Get your own AI podcast running in minutes.

1

Clone the Repository

git clone https://github.com/domcritchlow/vibecast.git
cd vibecast
2

Install Dependencies

python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
3

Configure Your Podcast

Edit podcast/config.yaml to set your title, sources, mood, and voice.

4

Set Up API Keys

OPENAI_API_KEY=your_key_here
R2_ACCOUNT_ID=your_account_id
R2_ACCESS_KEY_ID=your_access_key
R2_SECRET_ACCESS_KEY=your_secret_key
5

Generate Your First Episode

python -m podcast.run_daily

  • RSS news sources
